# REALCRED media credits

## Original project artwork

- `src/components/illustrations/HomeLoanScenes.jsx` — original REALCRED vector scenes for home, balance transfer, plot, personal, business, property, vehicle and education loan cards. Created for this project; animated in the page with CSS.
- `src/components/illustrations/HomeBankOfficeScene.jsx` — original flat illustration of a lending office branch for the homepage hero.
- `src/components/illustrations/HomeLoanCityScene.jsx` — original light-theme isometric financial district illustration, drawn in SVG for the homepage hero.
- `images/hero-architecture.svg` — original REALCRED architectural backdrop illustration. Created for this project and gently animated in the homepage hero.

## Bank marks

- `src/components/illustrations/LoanDocumentsScene.jsx` - original inline SVG artwork showing loan application papers and a pen in the document checklist section.
